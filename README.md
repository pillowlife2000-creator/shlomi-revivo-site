# שלומי רביבו · פרגולות ומסכי ZIP בצפון

דף נחיתה סטטי (HTML/CSS/JS, בלי build). מתפרסם ב-GitHub Pages מהענף `main`.

## מה לערוך
- `tracking.js`: שם העסק, טלפון, וואטסאפ, כתובת לשליחת טפסים ומזהי פיקסלים.
- `media.js`: תמונות הגלריה, לפני/אחרי, סרטונים ותמונת בעל העסק.
  התמונות שמסומנות `ai: true` הן הדמיות. כשמחליפים בעבודה אמיתית, מוחקים את `ai: true`.
- `index.html`: כל מה שמסומן `[__]` או בסוגריים צריך מילוי (מחירים, אחריות, זמני שירות, טקסט "מי אנחנו").
- `privacy.html`: טיוטת מדיניות פרטיות.

## הרצה מקומית
```
python3 -m http.server 8000
```
ואז לפתוח http://localhost:8000

הפונט Kav Geo נמצא ב-`media/fonts/` והלוגו ב-`logo/`.
